SNATCHER DS 내부 검증 패처 v26 / 한국어 0.81

공개 배포본이나 완성판이 아닙니다. 버그와 미검증 구간이 남아 있습니다.
공개 v0.1Demo는 1회성 패처이며 변경하지 않습니다. 정식 배포 전까지 공개 패처 업데이트는 없습니다.
기존 두 화면 터치 UI, 원본 그림·음성·음악과 전역 5개 저장 슬롯을 유지합니다.

1. 이 폴더에서 py -3 -m pip install -r requirements.txt 를 실행합니다.
2. Patch-development.cmd 에서 보유한 원본 CUE, BIOS, 새 출력 폴더를 지정합니다.
3. 생성된 snatcher_ds.nds 를 SD 카드로 복사합니다. 기존 snatcher_ds 저장 폴더는 먼저 백업하고 유지하세요.
4. 플레이어 소스 복원·재빌드는 REBUILD-PLAYER_KO.txt, PC 변환 DLL 재빌드는 REBUILD-CONVERTERS_KO.txt를 참조하세요.

사운드 테스트 v4 엔진을 반영했습니다.
FM 내부 계산 주기를 약 13.3 kHz로 낮춰 부하를 줄이고, 최종 출력은 32 kHz를 유지합니다.
일부 음색에 차이가 날 수 있습니다. 음질 차이와 끊김의 실기 체감은 아직 확인하지 않았습니다.
원본 6개 FM 채널, 음성·효과음 데이터와 게임 시간 기준을 유지합니다.
추가 PCM 연산 및 전투 화면 변환 최적화는 기존 샘플·픽셀과 일치하는지 검사했습니다.
최신 엔진의 초반 진행·폐공장 탈출·후반 전투·저장/불러오기 구간은 에뮬레이터 검사를 통과했습니다.
후반 전투에서 남은 소리 공급 지연이 있어 모든 끊김이 해결됐다는 뜻은 아닙니다.
이 패처는 개발 폴더·컴파일러 없이 원본에서 1,230개 리소스와 NDS를 생성했습니다.
동봉 소스와 원본 의존 헤더를 복원해 다시 빌드한 NDS는 사운드 테스트 v4와 바이트 단위로 일치합니다.
패처 출력에는 고지문과 파일 배치 차이가 있으나 실행 코드와 게임 리소스는 동일합니다.
기본 진행 경로 밖의 선택 분기는 미검증 상태이며 버그로 진행이 막힐 수 있습니다.
전체 실기 검수와 최종 배포 검증은 완료되지 않았습니다.
새 실행 파일에서 저장한 기록은 이전 실행 파일에서 읽지 못할 수 있으므로,
교체 전에 snatcher_ds 폴더 전체를 백업하세요. 기존 저장 기록의 불러오기는 검사했습니다.

원본 게임 그림·음성·음악·BIOS는 포함하지 않으며 사용자가 지정한 원본에서 재구성합니다.
포함 파일의 출처는 SOURCE-ORIGINS_KO.txt와 PROVENANCE.json, 외부 구성 요소의 고지는 licenses/ 및 각 third_party/에 있습니다.

원본 입력과 준비 사항

- 입력 게임은 수정되지 않은 북미판 Snatcher의 CUE와 CUE가 참조하는 모든 BIN 트랙입니다.
  한글패치된 디스크 이미지나 이미 만든 NDS를 원본 CUE 대신 지정하지 마세요.
  한국어 0.81 교체 문장은 이 패처에 포함되어 있고, 원본의 그림·음성·음악을 변환할 때 적용합니다.
- BIOS는 북미판 Sega CD BIOS이며 직접 준비해야 합니다. 지원하는 BIOS의 SHA-256:
  b1c2036b79467514eaaa69c76e5ba83801621e821059caa53cb921a0b21e3af4
  BIOS와 게임 파일 자체는 이 ZIP에 포함되지 않습니다.
- Windows x64와 Python 3.12 이상을 사용합니다. ZIP 전체를 한 폴더에 풀고 그 폴더에서
  py -3 -m pip install -r requirements.txt 로 동봉 목록의 의존성을 설치합니다.
  일반 NDS 생성에는 C 컴파일러나 개발용 프로젝트 폴더가 필요하지 않습니다.
- Patch-development.cmd 를 실행해 CUE, BIOS와 새 출력 폴더를 차례로 지정합니다.
  CUE 옆의 BIN 파일 이름·상대 경로를 유지하고, 변환 중 원본을 이동하거나 삭제하지 마세요.
  완료되면 SUCCESS와 SHA256 표시를 확인한 뒤 출력 폴더의 snatcher_ds.nds 를 사용합니다.
- 실기에서는 NDS 홈브루의 SD 접근을 지원하는 실행 환경이 필요합니다.
  기존 snatcher_ds 저장 폴더를 백업·유지하면 전역 5개 저장 슬롯을 계속 사용합니다.
  에뮬레이터의 SD/DLDI 지원과 저장 경로는 사용하는 코어에 따라 달라집니다.
- PACKAGE/DEPENDENCIES 오류는 의존성 설치와 ZIP 전체 압축 해제를 확인하고,
  BIOS 오류는 위 해시, 원본 리소스 오류는 수정되지 않은 북미판 CUE/BIN 구성을 확인하세요.
  변환 상세 기록은 선택한 출력 폴더의 conversion.json과 patch-result.json에 남습니다.

v26은 검증된 v25와 실행 코드·리소스가 같은 내부 후보이며 소스 복원·빌드 안내를 보완했습니다.
기존 승인된 그림 비율·터치 UI·한국어 0.81과 원본 리소스는 유지합니다.
공개 v0.1Demo 패처는 변경하지 않습니다.

최신 패처 출력의 새 프로필 ACT 1~3·엔딩·클리어 기록 연결 검사를 완료했습니다.
일반 터치 조작으로 34개 구간을 연결하고, 전역 5개 저장 슬롯과 재시작 후 클리어 기록을 확인했습니다.
전체 선택 분기나 실기 무끊김을 검증했다는 뜻은 아닙니다.
