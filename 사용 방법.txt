SNATCHER DS v0.811 · 전체 테스트용 EXE 패처

Windows 10/11 64비트용입니다. Python이나 개발 도구를 설치하지 않아도 됩니다.
변환은 사용자의 컴퓨터에서 이루어지며 ROM과 BIOS를 서버로 보내지 않습니다.
Mega-CD판 SNATCHER 한글패치 0.81을 기반으로 제작한 DS 이식의 전체 테스트용 배포입니다.
완성판이 아니며 버그, 일부 구간 진행 불가, 사운드 끊김이 남아 있을 수 있습니다.
기존 v0.1Demo와 별도 릴리스입니다. EXE 내부 도구 표기는 0.811 / 한국어 0.81입니다.

준비할 파일

• 수정되지 않은 북미판 Snatcher 원본 CUE와 모든 BIN 트랙
  CUE 파일에서 참조하는 BIN 파일 이름과 상대 경로를 유지하세요.
  BIN 파일 하나로 합쳐진 원본과 여러 BIN 트랙으로 나뉜 원본 모두 CUE로 지정합니다.
  한글패치된 ROM, NDS, ZIP, CHD, BIN 단독 파일은 입력으로 사용할 수 없습니다.
• 지원하는 북미판 Sega CD BIOS (131,072바이트)
  SHA-256: b1c2036b79467514eaaa69c76e5ba83801621e821059caa53cb921a0b21e3af4
• Windows 임시 폴더가 있는 드라이브에 약 300MB, 결과 저장 드라이브에 2GB 이상 여유 공간

만드는 방법

1. Snatcher-DS-v0.811-Patcher.exe를 실행합니다.
2. [원본 ROM (.cue)] 옆의 [찾아보기]로 원본 CUE를 선택합니다.
3. [Sega CD BIOS]에서 위 지원 BIOS를 선택합니다.
4. [저장 위치]에서 PC의 별도 NTFS 폴더를 선택합니다.
   원본 ROM/BIOS 폴더 안에는 저장할 수 없습니다. 먼저 PC에 만든 후 SD 카드로 복사하세요.
5. [NDS 만들기]를 누릅니다. 한국어 0.81은 자동으로 적용됩니다.
6. [완료 · snatcher_ds.nds 생성 및 검증 성공]이 표시되면 [결과 폴더 열기]를 누릅니다.
   Snatcher-DS-날짜-시간 폴더 안의 snatcher_ds.nds가 완성된 파일입니다.
7. NDS를 기기의 SD 카드로 복사합니다. 기존 snatcher_ds 저장 폴더는 백업하고 유지하세요.

진행 상태와 오류

• 최초 실행은 내장 실행 환경을 임시 폴더에 푸는 시간이 필요합니다.
• 변환에는 수 분이 걸리며 PC에 따라 더 오래 걸릴 수 있습니다.
  진행 막대는 활동 표시입니다. 퍼센트나 남은 시간 추정이 아닙니다.
• 창은 변환 중에도 응답합니다. [취소]를 누르면 변환 작업을 중단할 수 있습니다.
• 기존 결과는 덮어쓰지 않습니다. 다시 시작하면 새 결과 폴더를 만듭니다.
• 실패/취소 시 남은 .partial 파일은 미완성 파일이므로 실행하지 마세요.
  결과 폴더가 생겼다면 patcher.log와 conversion.json에서 자세한 기록을 볼 수 있습니다.
  출력 폴더가 생기기 전에 실패한 경우 [로그 열기]로 임시 기록을 확인하세요.
• BIOS 오류: 용량과 위 SHA-256을 확인하세요. 다른 지역/리비전 BIOS는 지원하지 않습니다.
• BIN 누락 오류: CUE가 참조하는 파일을 모두 준비하고 이름과 상대 경로를 복원하세요.
• 원본 일치 검사 오류: 한글패치나 다른 수정이 없는 북미판 원본인지 확인하세요.
• 설치가 필요 없는 실행 파일이며 관리자 권한도 필요하지 않습니다.

게임 상태

ACT 1~3 주 진행 경로, 엔딩, 전역 저장 5칸은 PC 에뮬레이터 검사에서 확인했습니다.
모든 선택 분기를 검증한 완성판은 아닙니다. 일부 선택/구간에는 버그와 진행 불가 가능성이
남아 있고, 특정 구간의 사운드 끊김도 남아 있습니다. 실기 무결점 동작을 보장하지 않습니다.
오프닝·게임 화면·조작·사운드 코드를 이번 EXE 포장 작업에서 변경하지 않았습니다.

파일과 소스

패처에는 원본 게임 그림·음성·음악·BIOS가 들어 있지 않습니다.
사용자가 지정한 원본에서 리소스를 변환하며 원본 파일을 수정하지 않습니다.
EXE에는 변환에 필요한 Python, NumPy, Pillow, Unicorn 및 고지문이 포함되어 있습니다.
ZIP의 runtime-licenses 폴더에 실행 환경 라이선스를 동봉합니다.
ZIP의 source 폴더에는 GUI 소스와 기존 원본 미포함 변환기 소스 키트가 들어 있습니다.
변환기와 플레이어 소스의 라이선스·재빌드 방법은 소스 키트의 안내를 참고하세요.


v0.811 호환성 안내

구형 RetroArch melonDS와 DeSmuME의 오프닝 리소스 읽기 문제를 보완했습니다. 구형 melonDS의 게임 내 저장·불러오기는 홈브루 SD 미지원으로 사용할 수 없습니다. melonDS DS의 홈브루 SD 기능과 구별하세요. R4 실기, melonDS 독립 실행판, Android APK의 이번 수정본 동작은 아직 별도 검증이 필요합니다. 기존 저장 폴더는 유지하고 NDS만 새로 만드세요.
