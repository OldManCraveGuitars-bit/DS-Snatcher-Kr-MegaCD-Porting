# v1.01 패치 방법

**SNATCHER DS 비공식 한글화·포팅 v1.01 정식 버전**입니다. [Mega-CD 한글패치](https://github.com/OldManCraveGuitars-bit/MegaCD-Snatcher-Kr)의 최종 번역을 자동 적용합니다.

## 준비

- Windows 10/11 64비트 PC. Python과 관리자 권한은 필요하지 않습니다.
- 수정되지 않은 북미판 원본 CUE와 모든 BIN 트랙. CUE가 참조하는 이름과 상대 경로를 유지하세요.
- 지원 USA BIOS: `us_scd2_9306.bin`, 131,072바이트.
- Windows 임시 드라이브 약 300MB, 결과 저장 드라이브 2GB 이상 여유 공간.

[원본 ROM·BIOS SHA-256](../INPUT-SHA256-v1.01.txt)을 확인하세요. BIOS는 기재된 해시와 일치해야 합니다. 이미 패치한 ROM, NDS, CHD, ZIP, BIN 단독 입력은 지원하지 않습니다.

## 만들기

1. **Snatcher-DS-v1.01-Patcher.exe**를 실행합니다. Python 설치는 필요하지 않습니다.
2. 수정되지 않은 **북미판 원본 CUE**, 연결된 **모든 BIN 트랙**, **지원 USA BIOS**를 준비합니다. ROM 선택란에는 CUE를 지정합니다.
3. PC의 새 결과 폴더를 지정하고 **NDS 만들기**를 누릅니다. 최종 한글 번역은 자동 적용됩니다.
4. 생성·검증이 완료되면 결과 폴더의 **snatcher_ds.nds**를 SD 카드로 복사합니다.
5. 이전 버전을 사용했다면 **기존 snatcher_ds 저장 폴더 전체를 백업하고 보존**한 채 NDS만 교체합니다.

저장 위치는 원본 ROM·BIOS 폴더 밖의 PC 폴더를 사용하세요. 변환에는 수 분이 걸릴 수 있으며, 진행 막대는 작업 중임을 나타냅니다. 기존 출력 폴더는 덮어쓰지 않습니다.

## 오류 또는 취소

- BIOS 오류: 파일 크기와 SHA-256을 확인합니다. 다른 지역·리비전은 지원하지 않습니다.
- BIN 누락: CUE가 참조하는 모든 파일과 상대 경로를 복원합니다.
- 원본 일치 검사 실패: 수정되지 않은 북미판인지 확인합니다.
- 취소·실패 후 `.partial` 파일은 실행하지 않습니다. `patcher.log`와 `conversion.json`을 확인하거나 ‘로그 열기’를 누릅니다.

파일은 PC에서 변환하며 ROM·BIOS를 서버로 보내지 않습니다. 원본과 기존 세이브를 변경하지 않습니다. 설치한 패처를 업데이트하는 방식이 아니므로 새 EXE로 새 NDS를 만드세요.

## 게임 내부 저장

홈브루 SD/DLDI 읽기·쓰기를 지원해야 합니다. 기존 `snatcher_ds` 폴더의 슬롯·설정·클리어 기록을 함께 보존하세요. 에뮬레이터의 강제 저장은 게임 내부 저장과 별개입니다. [조작과 저장](PLAYING_KO.md)

배포 ZIP에는 설명서·외부 라이선스·GUI·변환기·플레이어 대응 소스와 PyInstaller 런처 소스가 포함됩니다. [재빌드 안내](BUILDING.md)
