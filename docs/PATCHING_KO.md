# v0.1Demo 패치 방법

**버그가 남아 있는 개발 중 데모이며, 일부 구간만 플레이 가능합니다. 전체 게임을 끝까지 진행할 수 없습니다.**

**v0.1Demo 패처는 1회성 배포입니다. 이후 배포 버전이 나올 때까지 패처 업데이트를 제공하지 않습니다.**

## 준비물

- Windows 10/11 **64비트** PC와 64비트 Python 3.12 이상. 실제 검증은 Python 3.13에서 진행했습니다.
- 본인이 보유한 **미국판 SNATCHER 원본 CUE/BIN**. CUE에 적힌 모든 BIN 파일을 함께 두십시오. 번역 패치를 적용하지 않은 원본이 필요합니다.
- **Sega CD USA BIOS**. 지원 파일의 SHA-256은 다음과 같습니다. 파일명은 달라도 되지만 내용이 일치해야 합니다.

```text
b1c2036b79467514eaaa69c76e5ba83801621e821059caa53cb921a0b21e3af4
```

- 배포 ZIP을 풀 공간과 변환 결과를 둘 여유 공간. 작업 공간은 최소 1GB 정도를 확보하십시오. 원본 디스크 보관 공간은 별도입니다.

원본 게임·BIOS·한국어 패치된 디스크는 ZIP에 없습니다. 한국어 v0.775 텍스트·보이스 자막은 이식 엔진에 포함되어 있으므로, 입력 디스크에 별도로 한국어 패치를 적용하지 않습니다.

## 간편 실행

1. 릴리스의 `DS-Snatcher-Kr-MegaCD-Porting-v0.1Demo-Patcher.zip`을 새 폴더에 풉니다. ZIP 안에서 바로 실행하지 마십시오.
2. 해당 폴더에서 터미널을 열고 아래 명령으로 필요한 Python 패키지를 설치합니다. 인터넷 연결은 패키지 설치 시 필요하며, 변환은 로컬에서 진행합니다.

```powershell
py -3 -m pip install -r requirements.txt
```

3. `Patch-v0.1Demo.cmd`를 실행합니다.
4. 창에서 **미국판 원본 CUE → USA BIOS → 출력 폴더를 만들 위치** 순서로 선택합니다. 출력은 원본 디스크 폴더와 다른 위치로 지정하십시오.
5. 변환이 끝날 때까지 창을 닫지 마십시오. 음원 변환을 포함하므로 PC에 따라 수 분 이상 걸릴 수 있습니다.
6. `SUCCESS`가 출력되면 `Snatcher-DS-v0.1Demo-output` 폴더의 `DS-Snatcher-Kr-v0.1Demo.nds`를 사용합니다.

기존 결과 폴더를 덮어쓰지 않습니다. 다시 실행하려면 다른 위치 또는 새 출력 폴더 이름을 사용하십시오.

## 명령줄 실행

ZIP을 푼 폴더에서 다음과 같이 실행할 수 있습니다. 경로는 본인 PC에 맞게 바꾸십시오.

```powershell
py -3 -X utf8 -B patcher/patch_demo.py --source "D:/Original/Snatcher (USA).cue" --bios "D:/BIOS/bios_CD_U.bin" --output "D:/Snatcher-Demo-Output"
```

완성 NDS 크기는 **121,069,568바이트**, SHA-256은 아래와 같습니다. 패처가 입력 리소스와 결과를 검증합니다.

```text
0578ba7b425664ac5726d4e85f934dc9cf943d3bc6a9ab52bb2ce01667f42bd1
```

## 생성 파일과 기기로 복사

- `DS-Snatcher-Kr-v0.1Demo.nds`: 실행 파일. 필요한 게임 리소스는 내부 NitroFS에 포함됩니다.
- `patch-result.json`: 생성 결과와 최종 SHA-256.
- `resources/conversion.json`: 리소스 203개의 변환·검증 결과.
- `resources/`, `build-inputs/`: 변환 중간 결과와 개발자 재빌드 입력. NDS 실행 자체에는 별도로 복사할 필요가 없습니다.

기기에 NDS를 복사하고 홈브루 파일 저장을 지원하는 환경에서 실행하십시오. 저장 파일이 들어 있는 기기의 `snatcher_ds` 폴더는 삭제하지 마십시오. 생성 결과에는 원본 게임에서 유래한 자료가 포함되므로, 패처 ZIP 대신 결과 폴더 전체를 재배포하는 용도로 사용하지 마십시오.

## 실패하는 경우

- `py` 명령이 없으면 Python을 설치하고 터미널을 다시 여십시오. 32비트 Python은 지원하지 않습니다.
- `Unsupported ... BIOS`는 지원되는 BIOS 해시와 다르다는 뜻입니다.
- CUE/BIN 읽기 오류는 CUE의 파일명, 함께 있어야 하는 트랙 파일, 읽기 권한을 확인하십시오.
- 리소스 해시가 다르면 다른 판본, 변경된 디스크 또는 손상된 입력일 수 있습니다. 검증을 끄고 진행하지 않습니다.
- `PATCH FAILED`가 표시되면 해당 결과는 성공한 패치가 아닙니다. 콘솔 메시지와 `conversion.json`을 확인하십시오.

배포 파일에는 Windows x64용 변환 보조 라이브러리와 해당 소스가 포함됩니다. 일반 사용자는 C/C++ 컴파일러나 DS 개발 도구를 설치할 필요가 없습니다.
