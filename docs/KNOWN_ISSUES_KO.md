# 알려진 문제와 테스트 범위

**버그가 남아 있는 개발 중 데모이며, 일부 구간만 플레이 가능합니다. 전체 게임을 끝까지 진행할 수 없습니다.**

**v0.1Demo 패처는 1회성 배포입니다. 이후 배포 버전이 나올 때까지 패처 업데이트를 제공하지 않습니다.**

## 남은 문제

- **사운드 성능:** BGM·효과음·보이스가 끊기거나 늘어지는 문제가 남습니다. 사격 연습과 폐공장 탈출·복귀를 포함해 일부 구간은 실제 기기에서 느립니다. v41의 게임 구현을 기반으로 하며 사운드 완전 해결판이 아닙니다.
- **미완성 진행:** 검증 범위는 두 오프닝, 초기 본부, 사격 연습, 차량, 폐공장 조사·전투·탈출·본부 복귀의 주요 경로입니다. 이후 이야기·깁슨 후속 구간·엔딩과 모든 분기는 미완성 또는 미검증입니다. 진행 중 오류 메시지나 정지가 발생할 수 있습니다.
- **저장장치 호환성:** 홈브루 저장장치를 제공하지 않거나 쓰기를 지원하지 않는 에뮬레이터 코어에서는 저장이 실패합니다. Android의 기존 melonDS와 melonDS DS는 다른 코어입니다.
- **원작 재현:** 원본 명령·그림·스프라이트·음원에 기반한 이식입니다. 모든 화면·분기·음원 위상·처리 속도가 원작과 완전히 같다는 보장은 없습니다.
- **패처 환경:** Windows x64용입니다. 별도 64비트 Python과 requirements.txt의 패키지가 필요합니다. macOS·Linux·Android에서 패처 자체를 실행하는 배포본은 제공하지 않습니다.

## 검증과 한계

원본 CUE/BIN과 BIOS에서 리소스 203개를 독립 생성했으며 누락·해시 불일치 없이 NDS를 조립했습니다. 같은 결과 ROM으로 두 오프닝 자동 진행, 본부, 사격 연습, 폐공장 전투·탈출·복귀 및 저장·불러오기를 에뮬레이터에서 검사했습니다. [검증 기록](RELEASE_STATUS.md)

이 검사는 실제 DS의 끊김 없는 재생이나 전편 완성을 증명하지 않습니다. 전체 게임·모든 선택지·모든 플래시카드와 Android 기기를 검사한 것은 아닙니다.

## 문제 제보

버전, 기기/에뮬레이터와 정확한 코어 이름, 장소, 재현 조작, 필터 설정을 함께 남겨 주십시오. `snatcher_ds/runtime-error.txt` 또는 메뉴를 연 뒤 생기는 `audio-performance.txt`가 있으면 내용을 첨부할 수 있습니다. 원본 디스크나 BIOS 파일은 첨부하지 마십시오.

제보는 후속 개발에 참고하지만 **다음 배포 버전 전까지 v0.1Demo 패처를 업데이트하지 않습니다.**
