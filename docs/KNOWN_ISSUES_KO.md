# 알려진 문제 · 전체 테스트용 v0.811

**v0.811은 전체 테스트용 버전입니다. 완성판이 아니며, 버그·일부 구간의 진행 불가·사운드 끊김이 남아 있을 수 있습니다.**

- **진행 범위:** ACT 1~3·엔딩 주요 경로는 PC 에뮬레이터에서 확인했습니다. 모든 선택지·선택 순서·이전 저장 데이터·재방문 조건을 검사하지 않았습니다. 일부 구간이나 분기에서 정지 또는 진행 오류가 발생할 수 있습니다.
- **사운드:** BGM 처리 부하를 줄였지만 특정 장면에서 BGM·효과음·보이스가 끊기거나 늘어질 수 있습니다. 이번 최종 패키지가 모든 실기에서 부드럽게 재생된다는 검증은 없습니다.
- **화면·연출:** 그림 비율과 초상화 배치를 정리했지만 모든 연출·원작 하드웨어 타이밍의 완전 일치를 보장하지 않습니다.
- **저장:** 홈브루 SD/DLDI 읽기·쓰기를 지원하는 실행 환경이 필요합니다. 에뮬레이터/코어별로 지원이 다릅니다. 기존 저장 폴더를 백업하고 새 버전의 저장을 구버전에서 열지 마세요.
- **패처:** Windows 10/11 x64용입니다. 수정되지 않은 북미판 CUE/BIN과 안내된 BIOS만 지원합니다. CHD·압축파일·BIN 단독·이미 한글패치한 ROM은 직접 입력할 수 없습니다.
