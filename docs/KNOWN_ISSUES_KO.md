# v1.01 호환성과 남은 확인 사항

v1.01은 비공식 한글화·포팅 정식 배포입니다. 아래는 현재 검사 범위의 한계와 실행 환경별 참고사항입니다.

- **실기·분기:** 최종판으로 모든 선택 순서·재방문·기기 조합을 다시 완주하지 않았습니다. 변경 구간 검사와 이전 전체 주요 경로 기록은 [검증 범위](RELEASE_STATUS.md)에 구분합니다.
- **사운드:** 아우터헤븐 ‘암호의 의미’ 뒤 FM 잡음은 수정했고, 수정판 녹음에서 제보자가 잡음 해소를 확인했습니다. 최신 실기 전체 구간의 무끊김을 확인한 것은 아닙니다. 화면 필터를 켜면 전투 경량 표시 대신 기존 변환 경로를 사용합니다.
- **저장:** 홈브루 SD/DLDI 읽기·쓰기가 필요합니다. 검사한 구형 RetroArch melonDS 0.9.3 코어는 홈브루 SD를 제공하지 않아 내부 저장을 지원하지 않습니다. melonDS DS와 구분하세요.
- **기기:** R4 제품·커널별, melonDS 독립 실행판, Android APK의 최종판 호환성은 별도 확인이 필요합니다. DSi SD 옵션만으로 홈브루 SD 지원을 대신할 수 없습니다.
- **패처 입력:** 수정되지 않은 북미판 CUE/BIN과 안내된 BIOS를 사용합니다. CHD·ZIP·BIN 단독은 직접 입력하지 않습니다.
- **소리 설정:** 원본부터 음악과 음성이 섞인 CD 트랙은 배경음 설정을 따릅니다. 그 안의 목소리만 분리해 끄는 기능은 없습니다.

## v1.01에서 수정한 문제

폐공장 앞 정커 신분증 선택 시 PC16AC OP42 오류를 수정했습니다. 기존 v1.0에서도 재현된 내부 처리 문제이며, R4 전용 오류로 보지 않습니다.

## 문제 제보

[Issues](https://github.com/OldManCraveGuitars-bit/DS-Snatcher-Kr-MegaCD-Porting/issues)에 **v1.01 / 기기·플래시카드·커널 또는 정확한 에뮬레이터 코어 / ACT와 장소 / 직전 조작 / 반복 재현 여부**를 적어 주세요. 화면이나 게임 저장 파일은 재현에 도움이 됩니다. 원본 ROM·BIOS는 첨부하지 마세요.
