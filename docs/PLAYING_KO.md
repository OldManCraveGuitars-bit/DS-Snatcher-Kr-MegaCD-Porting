# 조작·저장 안내

이 문서는 v0.1Demo의 조작 설명입니다. 버그와 미구현 구간이 남아 있으며, 전편 플레이를 지원하지 않습니다.

## 기본 조작

일반 대사와 선택지는 하단 터치 화면으로 진행합니다. 화면에 나타난 `다음`, 선택 항목, `메뉴`, `돌아가기`를 누르십시오. 방향키와 A/B 조작도 지원하며, 음성이 재생되는 자동 진행 구간에는 입력이 잠길 수 있습니다. 자판이 필요한 장면은 하단 화면에서 입력합니다.

사격과 전투는 하단 표적을 터치하거나 방향키와 A로 조작합니다. X는 총을 꺼내거나 넣는 동작입니다. 상단에는 길리언의 초상화와 피해 연출이 표시됩니다.

## 저장·불러오기

게임의 `메뉴 → 저장하기`에서 슬롯을 고릅니다. 성공하면 `저장 완료.`가 표시됩니다. 불러오기는 `메뉴 → 불러오기`에서 저장한 슬롯을 선택합니다. 슬롯에는 ACT와 위치가 표시됩니다.

게임은 홈브루 저장장치의 `snatcher_ds` 폴더에 저장합니다. 이 폴더를 보존하십시오. 게임과 에뮬레이터가 종료된 상태에서 저장장치를 백업하는 방법을 권장합니다. 원본 Mega CD 세이브와 서로 교환하는 기능은 없습니다.

## Nintendo DS 계열 기기

일반 DS/DS Lite의 256×192 두 화면을 기준으로 제작했습니다. 게임 내 저장에는 홈브루 파일 읽기·쓰기를 제공하는 실행 환경이 필요합니다. 모든 플래시카드·기기 조합을 검증한 것은 아닙니다.

## Android RetroArch

사용 중인 코어의 정확한 이름을 확인하십시오. 기존 **melonDS**와 **melonDS DS**는 다른 코어입니다. melonDS DS의 공식 안내는 기존 코어와 달리 홈브루 저장 데이터를 지원한다고 설명합니다. 필요한 저장장치 설정과 파일 위치는 설치 버전의 안내를 확인하십시오. [melonDS DS 공식 홈브루 저장 설명](https://github.com/JesseTG/melonds-ds#homebrew-save-data)

`SD 카드를 읽을 수 없습니다.`가 표시되면 이 게임이 홈브루 저장장치를 초기화하지 못한 상태입니다. Android의 물리 SD 카드 고장이라고 단정하는 메시지는 아닙니다. 코어 이름, 홈브루 가상 SD 지원, RetroArch 저장 폴더의 쓰기 권한을 확인하십시오.

에뮬레이터의 강제 저장은 게임 내부의 저장 파일과 다릅니다. 홈브루 가상 SD는 강제 저장에 함께 보관되지 않을 수 있으므로 게임 내부 저장 기능을 사용하십시오. [공식 Libretro 문서](https://docs.libretro.com/library/melonds_ds/)

## 화면 설정

TV 필터와 스캔라인은 각각 켜고 끌 수 있고 함께 사용할 수 있습니다. 효과는 게임 그림에 적용되며, 장식 배경과 하단 글자의 색은 유지합니다. 사격장을 포함한 일부 구간의 사운드 끊김은 필터를 끄는 것만으로 해결되지 않을 수 있습니다.
