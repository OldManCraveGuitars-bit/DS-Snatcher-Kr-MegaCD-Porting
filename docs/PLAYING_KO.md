# v0.811 조작·저장 안내

전체 테스트용 버전입니다. 모든 선택 분기와 기기 조합의 동작을 보증하지 않습니다.

## 터치 조작

하단의 `다음`, 선택 항목, `메뉴`, `돌아가기`를 누릅니다. 자판 입력, 사격 표적, 손전등 조작도 하단 터치 UI를 사용합니다. 음성 자동 진행 중에는 대사 넘기기가 잠길 수 있습니다. 방향키와 A/B 등 기존 버튼 조작도 지원합니다.

## 저장과 ACT 선택

`메뉴 → 저장하기 / 불러오기`에서 5개 전역 슬롯을 사용합니다. 홈브루 저장장치의 `snatcher_ds` 폴더 전체를 백업하세요. 원본 Mega-CD 세이브를 그대로 불러오는 기능은 아닙니다.
엔딩을 마친 클리어 기록이 있으면 시작 메뉴에 숨겨진 ACT 선택이 나타납니다. 일반 저장 슬롯과 클리어 기록은 함께 보존하세요.
새 버전에서 저장한 파일은 더 오래된 실행 파일에서 읽지 못할 수 있습니다.

## 기기와 에뮬레이터

일반 DS/DS Lite의 4 MiB 메모리와 256×192 두 화면을 기준으로 개발·검사했습니다. 실기에서는 NDS 홈브루의 SD/DLDI 읽기·쓰기를 지원하는 실행 환경이 필요합니다. 모든 플래시카드·DSi/3DS 실행 환경·Android 코어를 검증한 것은 아닙니다.
에뮬레이터에서 `SD 카드를 읽을 수 없습니다.`가 표시되면 해당 코어의 홈브루 저장장치 지원과 저장 폴더 접근을 확인하세요. 에뮬레이터 강제 저장과 게임 내부 저장은 다릅니다.

## 화면 설정

TV 필터와 스캔라인은 각각 설정할 수 있습니다. 효과는 게임 그림에 적용되며 하단 글자는 선명하게 유지합니다. 소리 끊김은 화면 필터 설정만으로 해결되지 않을 수 있습니다.


v0.811 호환성 안내

구형 RetroArch melonDS와 DeSmuME의 오프닝 리소스 읽기 문제를 보완했습니다. 구형 melonDS의 게임 내 저장·불러오기는 홈브루 SD 미지원으로 사용할 수 없습니다. melonDS DS의 홈브루 SD 기능과 구별하세요. R4 실기, melonDS 독립 실행판, Android APK의 이번 수정본 동작은 아직 별도 검증이 필요합니다. 기존 저장 폴더는 유지하고 NDS만 새로 만드세요.
