# v1.01 검증 범위

폐공장 앞 정커 신분증 오류(`PC16AC OP42`)를 v1.0에서 재현한 뒤 수정했습니다.

- 새 게임에서 두 오프닝과 본부 출동을 거쳐 폐공장 도착·신분증 표시·저장·불러오기: 52,629 프레임.
- 기존 폐공장 저장에서 신분증 표시·저장·불러오기·복귀: 2,572 프레임.
- 재실행 후 신분증 화면 복구, 신분증 재표시와 현금 보기: 3,139 프레임.
- 경고 보이스 130~136, 동작 감지기 조사, 공장 진입과 내부 보기: 7,527 프레임. 측정 중 음향 버퍼 부족 없음.
- 실제 배포 EXE 출력에서도 해당 선택·저장·불러오기 검사 통과.
- 실제 EXE 전체 변환 약 457초. 입력 ROM·BIOS 해시 불변, 1,230개 리소스와 출력 NDS 일치.
- 공개 소스 복원·재빌드 결과가 수정판과 바이트 단위로 일치. 패처 출력의 실행 코드 4영역과 모든 리소스도 일치.
- 새 EXE 출력의 로고·타이틀까지 melonDS DS와 DeSmuME 코어에서 부팅 확인. DS 메모리 4 MiB.

게임 검사는 정상 터치 입력과 실제 게임 저장을 사용했습니다. RAM 주입과 에뮬레이터 세이브스테이트는 사용하지 않았습니다. Windows EXE 검사는 GUI 콜백·실제 동결 작업자 검사이며 수동 클릭 검사는 아닙니다.

이번 수정판의 실기 R4 확인·모든 분기·전편 재완주는 수행하지 않았습니다. [v1.0 검사](verification-v1.0.json)는 이전 버전 기록입니다. [v1.01 기계 판독 기록](verification-v1.01.json)
