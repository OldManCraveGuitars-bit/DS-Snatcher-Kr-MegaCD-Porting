# v0.1Demo 검증 기록

**버그가 남아 있고 일부 구간만 플레이 가능한 개발 데모입니다. 전체 이야기·엔딩·모든 분기를 검증한 버전이 아닙니다.**

패처는 완성된 NDS 생성까지 확인했습니다. v0.1Demo는 1회성 패처 배포이며, 이후 배포 버전이 나오기 전까지 패처 업데이트를 제공하지 않습니다.

## 패처와 소스

- 깨끗한 미국판 원본 CUE/BIN과 지원 USA BIOS에서 리소스 **203개를 독립 생성**했습니다. 두 차례 모두 누락·해시 불일치·변환 오류가 0개였습니다.
- 두 번째 검사는 새 Python 3.13 64비트 가상 환경에서 고정 의존성을 설치하고 **한글 출력 폴더**를 사용했습니다.
- 두 결과 NDS는 모두 **121,069,568바이트**이며 SHA-256이 같습니다.
- 배포 소스로 Windows 변환 보조 라이브러리 5개를 다시 빌드했습니다.
- 배포 소스로 DS 엔진도 다시 빌드하여 ARM9·ARM7 프로그램 바이트가 배포 엔진과 일치함을 확인했습니다. 빌드에는 기존 경고가 남아 있으며, 다른 SDK 버전까지 동일한 결과를 보장하지 않습니다.
- 원본 디스크와 BIOS는 수정하지 않았습니다. 배포본에는 원본 그림·음원·BIOS·완성 NDS를 넣지 않았습니다. 소개용 스크린샷은 별도 문서 자료입니다.

```text
0578ba7b425664ac5726d4e85f934dc9cf943d3bc6a9ab52bb2ce01667f42bd1
```

## 생성한 NDS의 에뮬레이터 검사

| 경로 | 검사한 디스플레이 프레임 | 결과 |
| --- | ---: | --- |
| 두 오프닝 자동 진행 → 접수처 → 저장/불러오기 → 본부 | 32,666 | 통과 |
| 오프닝 스킵 → 국장실·본부 → 사격 연습 → 저장/불러오기 | 20,990 | 통과 |
| TV 필터와 스캔라인을 함께 켠 사격 연습 | 21,053 | 통과 |
| 실제 게임 저장 체크포인트 → 폐공장 전투·탈출 → 본부 복귀·저장/불러오기 | 14,199 | 통과 |

합계 **88,908프레임**입니다. 전투·복귀 검사는 실제 저장 파일에서 시작했으며, 첫 시작부터 전편을 연속 완료한 검사가 아닙니다. 플레이 상태를 메모리에 주입하지 않았습니다. 복귀 보이스 자막 30개도 확인했습니다. 공개 스크린샷 4장은 이 NDS에서 캡처했습니다.

**실제 기기에서 사운드 끊김·늘어짐·속도 저하가 해결되었다는 의미는 아닙니다.** 이번 패키지의 별도 실기 검사는 하지 않았으며, 이전 실기 피드백의 사격장·폐공장 탈출 이후 오디오 문제를 알려진 문제로 유지합니다. 저장은 에뮬레이터의 홈브루 저장장치 지원에 따라 달라집니다.

검사 결과와 보고서 해시는 [verification.json](verification.json), 제외한 구형 미사용 리소스 39개의 근거는 [RESOURCE_AUDIT.json](RESOURCE_AUDIT.json)에 기록했습니다. [알려진 문제](KNOWN_ISSUES_KO.md)도 함께 확인하십시오.
