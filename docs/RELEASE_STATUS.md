# v1.0 검증 범위

**SNATCHER DS 비공식 한글화·포팅 1.0 정식 버전**의 검사 기록입니다. 최종 배포 파일 검사와 앞선 게임 진행 검사를 구분합니다.

## 패처와 공개 소스

- 실제 Windows EXE에 원본 CUE/BIN·지원 BIOS를 넣어 변환했습니다. 리소스 1,230개와 최종 NDS 해시가 일치했고, 입력 원본은 변하지 않았습니다. 이 PC에서 전체 변환은 약 492초 걸렸습니다.
- Python 없는 PATH, 한글·공백 경로, 실제 동결 EXE의 GUI 생성, 파일 선택 콜백, 잘못된 입력 거부, 취소·재시도, 진행·완료 상태를 검사했습니다. 수동 데스크톱 클릭 검사는 아닙니다.
- 공개 소스로 복원·재빌드한 NDS가 개발 빌드와 바이트 단위로 일치했습니다. 패처 출력은 파일 배치가 다르며 실행 코드 4영역과 리소스 1,230개는 같습니다.
- 소스 키트 627개 파일의 무결성·출처와 원본 의존 411영역(565,344바이트)의 제거·복원 상태를 검사했습니다. 원본 ROM·BIOS·완성 NDS는 배포 파일에 없습니다.

## 최종 EXE 출력 부팅

일반 DS 4 MiB, 새 프로필, 정상 터치 입력으로 두 오프닝을 건너뛰지 않고 접수처까지 진행했습니다. RAM 주입·세이브스테이트는 사용하지 않았습니다.

| Windows libretro 코어 | 결과 | 검사 프레임 |
| --- | --- | ---: |
| melonDS 0.9.3 66b5d26 | [접수처 도착](compatibility-v1.0/melonds-reception.png) | 28,611 |
| DeSmuME git 95b4d79 | [접수처 도착](compatibility-v1.0/desmume-reception.png) | 28,633 |

이는 melonDS 독립 실행판·Android APK·R4 실기 검사가 아닙니다. 구형 melonDS 0.9.3 코어의 게임 내부 저장은 홈브루 SD 미지원으로 사용할 수 없습니다.

## v1.0 변경 구간

- **최종 번역:** 13,077쪽 자막 아카이브와 패키지 리소스 1,230개를 검증했습니다. 최종 대사 검수 16개 실행 항목·보이스 자막 3쪽·누락 CD 자막 1쪽을 반영했으며, 이전 ACT3 번역 보완도 유지합니다. 기존 ID·음성 시각·게임 제어 그래프는 유지합니다.
- **ACT3 전투:** 실제 저장을 정상적으로 불러와 세 구간을 진행하고 대화 복귀까지 23,937프레임 검사했습니다. 표시된 체력, 원래 승리·무사격 판단 조건, 전투 종료 후 화면 복귀를 확인했습니다. 안정된 실제 LCD 69프레임을 독립 픽셀 계산과 대조했습니다. 측정 구간의 버퍼 복구·삽입 무음 증가는 모두 0입니다.
- **아우터헤븐:** 실제 슬롯 5에서 두 번째 ‘암호의 의미’를 선택하고 전후 3,697프레임을 검사했습니다. 측정 구간의 버퍼 복구·삽입 무음 증가는 모두 0입니다. 제거한 진단 메뉴 위치를 눌러도 실행되지 않습니다.
- **청감 확인:** 앞선 동일 FM 수정 코드의 녹음을 제보자가 ‘잡음 없이 정상으로 들림’으로 확인했습니다. 이는 녹음 청취 확인이며 v1.0 실기 전체 검사와는 다릅니다.
- **전투 경량 표시 조건:** TV 필터·스캔라인 Off에서 적용합니다. 같은 게임 코드의 앞선 audiofix2에서 두 필터를 켠 기존 표시 경로도 검사했습니다.

전투·아우터헤븐 검사는 v1.0 소스 빌드를 사용합니다. 배포 EXE 출력과 코드·리소스 일치를 별도로 확인했으며, 위 부팅 검사는 실제 EXE 출력으로 수행했습니다.
