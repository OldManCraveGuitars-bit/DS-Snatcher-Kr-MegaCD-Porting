# V0.95 검증 범위

**Mega-CD 한글패치 V0.95의 r57 번역을 적용한 전체 테스트용 버전입니다. 모든 분기·실기에서 검증을 마친 완성판은 아닙니다.**

## 패처와 소스

- 실제 Windows EXE로 원본 CUE/BIN·BIOS를 변환했습니다. 리소스 1,230개와 NDS가 기준 해시와 일치했습니다. 이번 PC에서 변환에 약 448초가 걸렸습니다.
- 한글·공백 경로, Python 없는 PATH, GUI 생성·파일 선택 콜백, 잘못된 입력 거부, 취소·재시도, 진행 표시를 검사했습니다. 수동 데스크톱 클릭 검사는 아닙니다.
- 공개 소스로 재빌드한 NDS가 개발 빌드와 완전히 일치했습니다. 패처 조립 결과는 파일 배치가 다르지만 실행 코드 4영역과 리소스 1,230개가 동일합니다.
- 소스 키트 624개 파일, 원본 유래 411영역(565,344바이트)의 제거 상태와 출처 기록을 검사했습니다. 원본 ROM·BIOS·완성 NDS는 공개 파일에 포함하지 않습니다.

## 실제 EXE 출력 부팅

일반 DS 4 MiB, 새 프로필, 정상 터치 입력으로 두 오프닝을 건너뛰지 않고 접수처까지 진행했습니다. RAM 주입·세이브스테이트는 사용하지 않았습니다.

melonDS 독립 실행판·Android APK·R4 실기 검사와는 다릅니다. 구형 RetroArch melonDS 0.9.3은 홈브루 SD를 제공하지 않으므로 게임 내부 저장에는 사용할 수 없습니다.

## 변경 구간

- V0.95 개발 빌드로 클리어 기록에서 ACT3를 선택해 제목·도입부·첫 질문까지 22,809프레임 진행했습니다. 측정 구간의 오디오 버퍼 복구 횟수 증가는 0회였습니다. 실기에서 들리는 잡음의 판정은 아닙니다.
- 원래 게임 저장을 정상적으로 불러와 CD12 연출을 진행하고 한국어 자막 **67쪽 모두 실제 하단 LCD와 대조**했습니다. 누락 자막이 기존 앞뒤 대사 사이에 나옵니다. 24,192프레임 검사입니다.
- V0.9 대비 기존 자막 81쪽 수정·누락 1쪽 추가, 총 13,076쪽을 검사했습니다. 기존 페이지 번호, 글꼴, 기존 자막 재생 시각과 게임 명령은 유지했습니다.
- 같은 게임 코드를 사용한 앞선 비공개 r57 빌드에서 비디오폰, 손전등, 길리언 입 표정, 시체 분석실, 오토바이, 택시·통로 전투, ACT3를 검사했습니다. 각 보고서의 빌드 해시를 JSON에 구분합니다. 이를 최종 EXE 전체 완주로 표시하지 않습니다.
- 믹서·필터 ARM 코드와 화면 합성은 독립 계산 결과, 원본 호출 동작과 비교했습니다. 사운드의 재생 속도·음성 파일은 유지하고 필터 계수를 65279/65536에서 255/256로 미세 조정했습니다.
- 앞선 r57의 같은 분석실 3,000프레임 비교에서 전체 활성 처리 시간은 약 2.25%, 그리기 시간은 약 6.22% 감소했습니다. 에뮬레이터의 특정 구간 비교이며 실기 전체 성능이나 청감 개선 수치가 아닙니다.

시작 메뉴 아래 화면의 ‘스네쳐’ 글씨를 제거하고 정상 부팅·불러오기 메뉴를 확인했습니다. 아우터헤븐 ‘암호의 의미’ 선택 뒤 BGM 잡음 제보는 미해결입니다. 원본 명령과 PC 버퍼 검사는 통과했으나 실기 청감이 정상이라는 뜻은 아닙니다.
