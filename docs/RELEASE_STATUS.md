# V0.9 검증 범위

**전체 테스트용입니다. 모든 분기·실기의 완전 검증 또는 완성판이라는 뜻은 아닙니다.**

## Windows EXE 패처

- 배포할 실제 EXE에서 원본 CUE/BIN·BIOS를 넣어 리소스 **1,230개**와 NDS 생성 완료. 이번 PC에서 약 450초 걸렸으며 기기별 시간은 다릅니다.
- Python 설치 경로 없이 GUI 생성, 한글·공백 경로, 잘못된 BIOS·누락 BIN·기존 출력 거부, 취소·재시도와 진행 표시를 검사했습니다. GUI 콜백 검사이며 수동 데스크톱 클릭 검사는 아닙니다.
- 모든 출력 리소스와 NDS 해시가 기준 결과와 일치했습니다. 원본 ROM·BIOS는 변경하지 않았습니다.
- 공개 소스로 재빌드한 NDS가 개발 빌드와 바이트 단위로 일치했습니다. 패처의 조립 레이아웃은 다르지만 실행 코드 4영역과 모든 리소스 1,230개가 동일합니다.
- 배포 소스 624개 파일, 원본 유래 영역 411곳의 제거 상태와 출처 기록을 검사했습니다. 원본 게임·BIOS·완성 NDS는 배포에 포함하지 않습니다.

Windows libretro 코어, 새 프로필, 일반 DS **4 MiB**, 보통 터치 입력을 사용했습니다. RAM 주입·세이브스테이트·오프닝 건너뛰기는 사용하지 않았습니다.

## 이번 변경 구간

- 체력을 사용하는 전투 **12종(단계 1~10·12·13)**에서 실제 LCD의 LIFE·여섯 칸 표시와 정상 승리 전환을 확인했습니다. 첫 폐공장 전투와 프레디 전투는 피해 0~6·게임오버·불러오기 후 체력 복구도 확인했습니다.
- ACT1·ACT2 사격 연습의 실제 진입 분기(단계 0)와 최종 판단(단계 14)에 불필요한 LIFE가 없는 것을 확인했습니다. 별도 연습 분기 11은 코드 검토만 수행했습니다.
- 전투별 검사는 동일한 체력 표시 코드의 중간 빌드와 V0.9 빌드에 걸쳐 진행했습니다. 최종 번역·아이콘 빌드로 첫 전투와 ACT1 최종 전투·종료·저장·ACT2 재개를 다시 확인했습니다. 각 ROM 해시는 아래 JSON에 구분했습니다.
- ACT1 END 장면의 서로 다른 화면 73개를 검사했고, 검은 화면을 제외한 71개에서 제목 외의 그림이 새어 나오지 않았습니다.
- ACT1 클리어 저장을 실제로 쓰고 장소 공란과 ACT1 표시를 확인한 뒤, 그 저장을 불러와 ACT2까지 진행했습니다. ACT2 클리어 장소 규칙은 호스트에서 검사했습니다. 저장 요약 규칙 3,842,560개 조합 중 의도한 4개만 바뀌었습니다.
- V0.9 번역의 STP 13,075쪽을 검사했습니다. 일반 대사 4개·음성 22개(27쪽)·회상 30쪽 변경 외 나머지 글과 시각은 유지했습니다. ACT2 회상 **75쪽 모두 실제 하단 LCD 글자와 대조**했습니다.
- 새 실행 아이콘의 1,024픽셀·16색·CRC·제목과 NDS 포함 상태를 검사했습니다. 플래시카드 메뉴의 실제 표시는 미검증입니다.
- 소리 On/Off는 앞선 설정 빌드에서 실제 메뉴·무음·유음과 호스트 검사를 수행했고 이번에 유지했습니다. 원본부터 합쳐진 CD 트랙은 배경음 설정을 따릅니다.
